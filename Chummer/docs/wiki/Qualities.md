# qualities.xml

qualities.xml (and custom_qualities.xml, see [Custom Data Files](Custom-Data-Files)) contains all of the information for Qualities.

Quality levels that replace one another, such as the SINner ranks, are defined separately in [Quality Levels](Quality-Levels).

# Structure

```xml
<chummer>
  <categories>
    <category />
  </categories>
  <qualities>
    <quality />
  </qualities>
</chummer>
```

[**categories**](#categories "categories") names the quality categories shown in selection.

[**quality**](#quality "quality") nodes describe individual Qualities.

## <a id="categories"></a>Categories Node

**category** (required): category name. The quality's own `category` text is what sets its type. `Negative` is a negative quality. `LifeModule` is a life-module quality. Every other value, including `Positive` and an empty value, is stored as a positive quality.

## <a id="quality"></a>Quality Node

**id** (required): GUID. All ID fields are standard GUIDs, which can be generated by [external websites](https://www.guidgenerator.com) or plugins.

**name** (required): the name of the Quality.

**category** (required): `Positive`, `Negative`, or `LifeModule`. See [**Categories**](#categories "Categories Node").

**karma** (optional): integer Karma cost. Positive qualities use a positive number. Negative qualities use a negative number. When omitted, Karma stays `0`.

**source** / **page** (optional): book reference. See [books.xml](Books "books.xml").

**bonus** (optional): improvements granted by the quality. See [Improvement Manager](Improvement-Manager).

**firstlevelbonus** (optional): improvements applied only when the quality is created at level 0. Later levels use `bonus`.

**naturalweapons** (optional): treated as another bonus node and passed to the Improvement Manager. Use this for natural weapons granted by the quality.

**addweapon** (optional): weapon name or id from [weapons.xml](Weapons "weapons.xml"). This element may appear more than once. The optional `rating` attribute is an integer Rating. The created weapon's Cost is set to `0`.

**limit** (optional): how many copies a character may take. `False` means unlimited. A number, including an attribute or limb expression such as `{arm} - 1`, is the maximum. When `limit` is omitted, qualities default to one copy. `chargenlimit` is used instead during character creation when it is present.

**nolevels** (optional): empty element. When present, the selection window does not treat extra copies as levels of the same quality, and the display name does not append a level count from the catalog entry.

**costdiscount** (optional): requirements block with a `value` child. When the requirements are met, `value` is added to the Karma of a positive quality and subtracted from the Karma of a negative quality. See [Conditions](Conditions).

**metagenic** (optional): when `True`, the quality counts as metagenic. `metagenetic` is still accepted for older custom data.

**doublecareer** (optional): when not `False`, career-mode purchase uses the doubled Karma cost in the selection filter.

**canbuywithspellpoints** (optional): when `True`, the quality may be bought with spell points.

**stagedpurchase** (optional): when `True`, the quality can be bought in stages.

**contributetobp** (optional): when `True`, the quality contributes to the build-point total.

**contributetolimit** (optional): when `True`, the quality contributes to the metagenic limit.

**implemented** (optional): when `False`, the quality is shown as not implemented.

**print** (optional): when `False`, print handling for the quality is disabled. Defaults to printing when omitted.

**mutant** (optional): the element sets the mutant flag by being present. Its text is not parsed.

**stage** (optional): life-module stage name. Read only when `category` is `LifeModule`.

**required** / **forbidden** (optional): selection rules evaluated by the shared requirements check. See [Conditions](Conditions).

**hide** / **ignoresourcedisabled** (optional): sourcebook-filter visibility. An empty `hide` element removes the quality from filtered selection lists.

**chargenonly** / **careeronly** / **onlyprioritygiven** (optional): empty elements enforced by the shared selection rules. `onlyprioritygiven` blocks the quality unless the character is built with priority tables.

**notes** / **altnotes** / **notesColor** (optional): default notes text and highlight color. `altnotes` is preferred when both are present.
