# powers.xml

powers.xml (and custom_powers.xml, see [Custom Data Files](Custom-Data-Files)) contains adept powers and adept-way enhancements.

# Structure

```xml
<chummer>
  <powers>
    <power />
  </powers>
  <enhancements>
    <enhancement />
  </enhancements>
</chummer>
```

[**power**](#power "power") nodes describe adept powers.

[**enhancement**](#enhancement "enhancement") nodes describe enhancements associated with a power or with initiation.

## <a id="power"></a>Power Node

**id** (optional): GUID stored as the power's source id. Creation does not warn when it is missing.

**name** (required): the name of the power.

**points** (optional): Power Point cost per level, stored as text so it may be a fraction such as `0.25`.

**levels** (optional): when `True`, the power has a rating. When omitted or any other value, the power's maximum rating is 1.

**maxlevel** (optional): integer cap on the rating. `maxlevels` is read when `maxlevel` is absent. A missing or non-positive value means no data cap. The effective cap is then Magic, unless rule enforcement is ignored. A power that boosts a skill is also capped by that skill's learned rating, or by learned rating plus half of learned rating when the increased Improved Ability option is on.

**limit** (optional): how many separate copies may be taken. This is not the rating cap. `False` means unlimited. When `limit` is omitted, powers are unlimited, unlike qualities. `chargenlimit` replaces `limit` during character creation when it is present. The stock file uses `1` so each power can be taken once.

**action** (optional): action type stored on the power, such as `Free` or `Simple`.

**adeptway** (optional): Power Point discount applied when the power is taken with an adept way.

**adeptwayrequires** (optional): requirements block stored on the power and checked before the adept-way discount is offered. Child content uses the shared requirements vocabulary. See [Conditions](Conditions).

**bonus** (optional): improvements granted by the power. The improvement rating is the power's total rating. See [Improvement Manager](Improvement-Manager).

**enhancements** (optional): `enhancement` children that are already installed when the power is created. These are loaded as saved enhancements, not looked up from the catalog list below.

**source** / **page** (optional): book reference. See [books.xml](Books "books.xml").

**required** / **forbidden** (optional): selection rules. See [Conditions](Conditions).

**hide** / **ignoresourcedisabled** (optional): sourcebook-filter visibility. An empty `hide` element removes the power from filtered selection lists.

**discounted** / **discountedgeas** (optional): when `True`, the power is created already marked as discounted by an adept way or a geas. These are normally character-state flags rather than catalog data.

**bonussource** (optional): text stored as the source of the power's bonus.

**freepoints** (optional): decimal Power Points that do not count against the character's pool.

**extrapointcost** (optional): decimal extra Power Point cost.

**notes** / **altnotes** / **notesColor** (optional): default notes text and highlight color. `altnotes` is preferred when both are present.

## <a id="enhancement"></a>Enhancement Node

Catalog enhancements live under `enhancements/enhancement` and are chosen from the initiation enhancement list.

**id** (required): GUID. All ID fields are standard GUIDs, which can be generated by [external websites](https://www.guidgenerator.com) or plugins.

**name** (required): the name of the enhancement. When `bonus` asks the user to choose a value, that choice is appended to the name in parentheses.

**power** (optional): name or id of the adept power this enhancement is added to. After creation, the character looks for a power with that name or source id and attaches the enhancement to it. When the element is empty or no matching power is on the character, the enhancement is stored on the character instead. `Enhancement` itself does not store this field.

**source** / **page** (optional): book reference. See [books.xml](Books "books.xml").

**bonus** (optional): improvements granted by the enhancement. See [Improvement Manager](Improvement-Manager).

**required** / **forbidden** (optional): selection rules. See [Conditions](Conditions). The stock entries require the parent power and an adept-way quality.

**hide** / **ignoresourcedisabled** (optional): sourcebook-filter visibility.

**notes** / **altnotes** / **notesColor** (optional): default notes text and highlight color. `altnotes` is preferred when both are present.

**grade** (optional): integer initiation grade stored when the enhancement is created from data. The initiation UI overwrites this with the grade the enhancement was added to.
