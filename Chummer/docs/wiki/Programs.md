# programs.xml

programs.xml (and custom_programs.xml, see [Custom Data Files](Custom-Data-Files)) contains AI programs. Matrix programs that are purchased as gear live in [gear.xml](Gear "gear.xml"), not here.

# Structure

```xml
<chummer>
  <categories>
    <category />
  </categories>
  <programs>
    <program />
  </programs>
</chummer>
```

[**categories**](#categories "categories") names the program categories shown in selection.

[**program**](#program "program") nodes describe individual AI programs.

## <a id="categories"></a>Categories Node

**category** (required): category name. The Select AI Program window lists these categories and can filter on them. A program whose category is exactly `Advanced Programs` is stored as an advanced program.

## <a id="program"></a>Program Node

**id** (required): GUID. All ID fields are standard GUIDs, which can be generated by [external websites](https://www.guidgenerator.com) or plugins.

**name** (required): the name of the program.

**category** (required): must match a category from the [**Categories** Node](#categories "Categories Node") if it should appear in that filter. Only the exact text `Advanced Programs` changes program behavior.

**require** (optional): name of another program that must already be on the character. The selection window reads this field and blocks the program when the requirement is missing. This is a single name, not a [Conditions](Conditions) block.

**bonus** (optional): improvements granted when the program is learned. A selected bonus value is stored as the program's extra text. See [Improvement Manager](Improvement-Manager).

**source** / **page** (optional): book reference. See [books.xml](Books "books.xml").

**required** / **forbidden** (optional): selection rules evaluated by the shared requirements check, in addition to `require`. See [Conditions](Conditions).

**hide** / **ignoresourcedisabled** (optional): sourcebook-filter visibility. An empty `hide` element removes the program from filtered selection lists.

**notes** / **altnotes** / **notesColor** (optional): default notes text and highlight color. `altnotes` is preferred when both are present.

`cost` and `avail` appear on stock entries. Neither `AIProgram` nor the selection window reads them.
