# metamagic.xml

metamagic.xml (and custom_metamagic.xml, see [Custom Data Files](Custom-Data-Files)) contains metamagics and arts. Echoes are a separate file, documented in [Echoes](Echoes). The metamagic class loads an echo when its improvement source is an echo, using the same fields it reads from a metamagic node.

# Structure

```xml
<chummer>
  <metamagics>
    <metamagic />
  </metamagics>
  <arts>
    <art />
  </arts>
</chummer>
```

[**metamagic**](#metamagic "metamagic") nodes describe initiations and submersion metamagics.

[**art**](#art "art") nodes describe magical arts.

## <a id="metamagic"></a>Metamagic Node

**id** (required): GUID. All ID fields are standard GUIDs, which can be generated by [external websites](https://www.guidgenerator.com) or plugins.

**name** (required): the name of the metamagic. When `bonus` asks the user to choose a value, that choice is appended to the name in parentheses.

**adept** (optional): `True` or `False`. When a character is an adept and not a magician, the selection list keeps only entries whose `adept` element is `True`.

**magician** (optional): `True` or `False`. When a character is a magician and not an adept, the selection list keeps only entries whose `magician` element is `True`. A character who is both, or who has no Magic, is not filtered by these elements.

**source** / **page** (optional): book reference. See [books.xml](Books "books.xml").

**bonus** (optional): improvements granted by the metamagic. The improvement rating is the character's Submersion Grade when that grade is greater than 0, otherwise the Initiate Grade. See [Improvement Manager](Improvement-Manager).

**required** / **forbidden** (optional): selection rules. The selection window applies them when the limit-to-available list is checked, and again when the choice is accepted. See [Conditions](Conditions).

**limit** (optional): how many copies may be taken. `False` means unlimited. When omitted, metamagics are unlimited. The stock Power Point entry uses `False` so it can be taken more than once.

**grade** (optional): integer grade stored when the node is created from data. Initiation normally sets the grade from the initiation grade being purchased, not from this element.

**hide** / **ignoresourcedisabled** (optional): sourcebook-filter visibility. An empty `hide` element removes the entry from filtered selection lists.

**notes** / **altnotes** / **notesColor** (optional): default notes text and highlight color. `altnotes` is preferred when both are present.

## <a id="art"></a>Art Node

Arts are selected from `arts/art`.

**id** (required): GUID. All ID fields are standard GUIDs, which can be generated by [external websites](https://www.guidgenerator.com) or plugins.

**name** (required): the name of the art. When `bonus` selects a value, that value is appended to the name in parentheses.

**source** / **page** (optional): book reference. See [books.xml](Books "books.xml").

**bonus** (optional): improvements granted by the art. The improvement rating passed in is always `1`. See [Improvement Manager](Improvement-Manager).

**required** / **forbidden** (optional): selection rules, applied when the limit-to-available list is checked and again when the choice is accepted. See [Conditions](Conditions).

**grade** (optional): integer grade stored from the data node at creation.

**hide** / **ignoresourcedisabled** (optional): sourcebook-filter visibility.

**notes** / **altnotes** / **notesColor** (optional): default notes text and highlight color. `altnotes` is preferred when both are present.
