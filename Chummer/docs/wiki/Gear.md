# gear.xml

gear.xml (and custom_gear.xml, see [Custom Data Files](Custom-Data-Files)) contains all of the information for Gear.

# Structure

[**categories**](#categories "categories") describes the different Categories of Gear.

[**gear**](#gear "gear") nodes describe the individual pieces of Gear.

## <a id="categories"></a>Categories Node

**category** (required): the name of the Gear Category. This list populates the Category list found in the Select Gear window. The optional `blackmarket` attribute groups the category for black-market pipelines. Several pipelines may be listed, separated by commas (for example `blackmarket="Electronics,Software"`).

## <a id="gear"></a>Gear Node

**id** (required): the internal name of the Gear. All ID fields are standard GUIDs, which can be generated by [external websites](https://www.guidgenerator.com) or plugins. All ID fields are standard GUIDs, which can be generated by [external websites](https://www.guidgenerator.com) or plugins.

**name** (required): the name of the Gear. The name `Custom Item` prompts the user for a name unless a forced value is already supplied.

**category** (required): the Category that this Gear belongs to. This must match one of the Categories defined in the [**Categories** Node](#categories "Categories Node"). Gear in the categories _Foci_ and _Metamagic Foci_ does not apply its `bonus` when the item is first added, unless that bonus contains `selectweapon`. Focus bonuses are applied when the focus is bonded.

**source** (required): the code for the Sourcebook that this entry comes from. See [books.xml](Books "books.xml").

**page** (required): the page number this item can be found on in the Sourcebook.

**avail** (optional): the Availability of the Gear. When omitted, Availability is left empty.

**cost** (optional): the Cost of the Gear. Supports `Variable(min-max)` and `Variable(min+)`. When omitted, Cost is stored as an empty string. A plugin created from `gears` is given a Cost of `0`.

**costfor** (optional): decimal quantity the item is priced for. Creating the Gear also sets its starting quantity to this value. The Select Gear window reads this field when displaying cost.

**capacity** (optional): Capacity string. A value enclosed in square brackets is treated as Capacity consumed when the item is installed as a plugin. Select Gear uses this to separate plugins from standalone gear.

**armorcapacity** (optional): Capacity string used when the Gear is installed in Armor. Select Gear can filter on this field instead of `capacity`.

**rating** (optional): maximum Rating. The value `0` is treated as no Rating. May contain formulas, including the `Parent` keyword.

**minrating** (optional): minimum Rating. May contain formulas, including the `Parent` keyword. When either bound contains `Parent` and the Gear has no parent yet, the requested Rating is not clamped at creation.

**ratinglabel** (optional): string-table key for a custom rating prompt label.

**weight** (optional): encumbrance string. When omitted, weight is stored as an empty string.

**bonus** (optional): a bonus node applied when the Gear is created, subject to the Foci rule above. See [Improvement Manager](Improvement-Manager).

**wirelessbonus** (optional): like `bonus`, but only applies when the Gear's wireless bonus is active. New Gear is created with wireless off.

**addweapon** (optional): weapon name or id from [weapons.xml](Weapons "weapons.xml"). This element may appear more than once. The optional `rating` attribute sets the created weapon's Rating and may contain `{Rating}`. The created weapon's Cost is set to `0` and its parent is this Gear.

**weaponbonus** (optional): bonus node applied to a weapon when this Gear is loaded as ammunition.

**flechetteweaponbonus** (optional): bonus node used instead of `weaponbonus` when the ammunition is flechette.

**isflechetteammo** (optional): when `True`, this ammunition is flechette ammunition.

**ammoforweapontype** (optional): weapon type or category this ammunition is limited to. Unless the attribute `noextra="True"` is set, creating the Gear prompts for a weapon category and stores it as the item's extra value.

**devicerating** (optional): matrix device rating.

**programs** (optional): program limit string for matrix devices.

**canformpersona** (optional): whether the device can form a persona.

**matrixcmbonus** (optional): integer matrix condition monitor bonus.

**attributearray** (optional): comma-separated Attack, Sleaze, Data Processing, and Firewall values. When present, the device can swap those attributes. Individual `attack`, `sleaze`, `dataprocessing`, and `firewall` elements are read only when `attributearray` is absent.

**modattributearray** / **modattack** / **modsleaze** / **moddataprocessing** / **modfirewall** (optional): matrix attribute modifiers.

**childcostmultiplier** (optional): integer cost multiplier applied to child Gear.

**childavailmodifier** (optional): integer Availability modifier applied to child Gear.

**allowrename** (optional): when `True`, the Gear may be renamed during character creation.

**gears** (optional): bundled child Gear. See [**Gears** Node](#gears "Gears Node").

**required** / **forbidden** (optional): selection rules. Select Gear evaluates `required/parentdetails`, `forbidden/parentdetails`, `required/geardetails`, and `forbidden/geardetails`, and then the shared requirements check. See [Conditions](Conditions).

**hide** (optional): empty element. Selection lists built with the sourcebook filter exclude the entry when this element is present.

**ignoresourcedisabled** (optional): when present, this entry remains selectable even if its sourcebook is disabled.

**notes** / **altnotes** / **notesColor** (optional): default notes text and highlight color. `altnotes` is preferred when both are present.

**stolen** (optional): when `True`, the Gear is created marked as stolen.

## <a id="gears"></a>Gears Node

Bundled plugins are listed under `gears`.

### usegear

**name** (required unless `category` is set): catalog Gear name to install. Optional attributes on `name`:

- `select`: forced bonus selection
- `qty`: decimal quantity, default `1`
- `createchildren`: when `False`, the child's own bundled gear is not created
- `addimprovements`: when `False`, the child's improvements are not created

**category** (optional): catalog Category. Combined with `name` when both are present. When `name` is omitted, the first Gear in this Category is used.

**rating** (optional): integer Rating passed to the child.

**capacity** (optional): replaces the child's Capacity with this string. The brackets are not added automatically.

**source** / **page** (optional): override the child's sourcebook reference.

The child's Cost is set to `0`.

### choosegear

Presents a list of `usegear` children and installs the one the user picks. Each candidate is skipped when its catalog entry's `forbidden/geardetails` matches the parent, or when its `required/geardetails` does not.

**name** (optional): label for the selection prompt.

**required** (optional): when the text is `True`, cancelling the prompt or having no legal choices aborts creation of the remaining bundled children.

**usegear** (required): one or more candidates, using the same fields as [**usegear**](#gears "Gears Node").
