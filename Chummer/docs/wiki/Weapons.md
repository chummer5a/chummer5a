# weapons.xml

weapons.xml (and custom_weapons.xml, see [Custom Data Files](Custom-Data-Files)) contains all of the information for Weapons and Weapon Accessories.

# Structure

[**categories**](#categories "categories") describes the different Categories of Weapons.

[**weapon**](#weapon "weapon") nodes describe individual Weapons.

[**accessory**](#accessory "accessory") nodes describe Weapon Accessories.

Clips are not catalog entries. They are created from a weapon's ammo slots when the weapon is created. See [**Clips**](#clips "Clips").

## <a id="categories"></a>Categories Node

**category** (required): the name of the Weapon Category. This list populates the Category list found in the Select Weapon window. The optional `blackmarket` attribute groups the category for black-market pipelines.

**type** (optional attribute): used as the weapon's type when the weapon entry omits `weapontype`. Stock values include `melee`, `gun`, `bow`, `crossbow`, `taser`, `energy`, `flame`, `glauncher`, `mlauncher`, `cannon`, and `exotic`.

**gunneryspec** (optional attribute): Gunnery specialization for this Category, such as `Ballistic`, `Energy`, `Artillery`, or `Rocket`. A weapon checks `category/@gunneryspec` on its own category element first, then this attribute on the matching Categories entry. When neither is set, the specialization is `None`.

## <a id="weapon"></a>Weapon Node

**id** (required): the internal name of the Weapon. All ID fields are standard GUIDs, which can be generated by [external websites](https://www.guidgenerator.com) or plugins. All ID fields are standard GUIDs, which can be generated by [external websites](https://www.guidgenerator.com) or plugins.

**name** (required): the name of the Weapon.

**category** (required): the Category that this Weapon belongs to. This must match one of the Categories defined in the [**Categories** Node](#categories "Categories Node"). Saved characters still named `Hold-Outs` or `Cyberware Hold-Outs` are rewritten to `Holdouts` and `Cyberware Holdouts`.

**type** (optional): `Melee` or `Ranged`, stored as written.

**source** (required): the code for the Sourcebook that this entry comes from. See [books.xml](Books "books.xml").

**page** (required): the page number this item can be found on in the Sourcebook.

**accuracy** (optional): Accuracy. May be a formula.

**damage** (optional): Damage string, such as `8P` or `STR+1P`.

**ap** (optional): Armor Penetration.

**mode** (optional): firing modes, such as `SA/BF/FA`.

**rc** (optional): Recoil Compensation.

**ammo** (optional): ammunition capacity string, such as `10(c)` or `6(cy)`. A weapon whose `useskill` is `Throwing Weapons` and whose ammo is not exactly `1` is forced to ammo `1`.

**conceal** (optional): Concealability modifier.

**avail** (optional): Availability.

**cost** (optional): Cost. Supports `Variable(min-max)` and `Variable(min+)`.

**weight** (optional): encumbrance string.

**reach** (optional): Reach.

**mount** / **extramount** (optional): mount slots used when this weapon is itself mounted, such as an underbarrel weapon.

**accessorymounts** (optional): contains one or more `mount` children. Their text is joined with `/` and stored as the weapon's accessory slots.

**doubledcostaccessorymounts** (optional): same shape as `accessorymounts`. Accessories installed in these slots have their cost doubled.

**ammoslots** (optional): integer number of ammunition clips created with the weapon. Defaults to `1` when omitted or not an integer.

**ammocategory** (optional): Gear Category used when selecting ammunition for this weapon.

**requireammo** (optional): when `True`, the weapon requires ammunition gear. Weapons that do not require ammunition and have a non-empty ammo value other than `0` use a single internal clip sized from the ammo string.

**cyberware** (optional): when `True`, the weapon is a cyberweapon. Select Weapon skips cyberweapons unless it is selecting a cyberweapon.

**sizecategory** (optional): size category used by weapon mounts and similar filters.

**weapontype** (optional): overrides the Category `type` attribute. When omitted, the Category attribute is used, and if that is also missing the Category name is lowercased.

**range** (optional): range category name when it differs from the Category default. The optional `multiply` attribute is parsed as a decimal range multiplier.

**alternaterange** (optional): alternate range category. Leading and trailing whitespace is removed.

**singleshot** / **shortburst** / **longburst** / **fullburst** / **suppressive** (optional): integer extra dice for that firing mode.

**allowsingleshot** / **allowshortburst** / **allowlongburst** / **allowfullburst** / **allowsuppressive** (optional): when `True`, that firing mode is offered even if `mode` would not include it.

**useskill** (optional): skill used to attack with this weapon, when it is not the skill implied by the Category.

**useskillspec** (optional): skill specialization used with `useskill`.

**spec** / **spec2** (optional): additional specialization names stored on the weapon.

**rating** (optional): maximum Rating. The value `0` is treated as no Rating.

**minrating** (optional): minimum Rating.

**ratinglabel** (optional): string-table key for a custom rating prompt label.

**allowaccessory** (optional): when `False`, the weapon cannot take accessories. Underbarrel weapons created from this weapon inherit that restriction.

**devicerating** (optional): matrix device rating.

**programs** (optional): program limit string for matrix devices.

**attributearray** (optional): comma-separated Attack, Sleaze, Data Processing, and Firewall values. When present, the device can swap those attributes. Individual `attack`, `sleaze`, `dataprocessing`, and `firewall` elements are read only when `attributearray` is absent.

**modattributearray** / **modattack** / **modsleaze** / **moddataprocessing** / **modfirewall** (optional): matrix attribute modifiers.

**wirelessbonus** / **wirelessweaponbonus** (optional): bonus nodes applied when the weapon's wireless bonus is active. See [Improvement Manager](Improvement-Manager).

**underbarrels** (optional): each child element's text is a weapon name or id installed as an included underbarrel weapon with Cost `0`.

**addweapon** (optional): additional weapon name or id. This element may appear more than once. The optional `rating` attribute sets the created weapon's Rating and may contain rating tokens. The created weapon's Cost is set to `0`.

**accessories** (optional): accessories installed with the weapon. See [**Included Accessories**](#included_accessories "Included Accessories").

**required** / **forbidden** (optional): selection rules. Select Weapon evaluates `required/weapondetails` and `forbidden/weapondetails`, then the shared requirements check. See [Conditions](Conditions).

**hide** (optional): empty element. Selection lists built with the sourcebook filter exclude the entry when this element is present.

**ignoresourcedisabled** (optional): when present, this entry remains selectable even if its sourcebook is disabled.

**notes** / **altnotes** / **notesColor** (optional): default notes text and highlight color. `altnotes` is preferred when both are present.

**stolen** (optional): when `True`, the weapon is created marked as stolen.

## <a id="included_accessories"></a>Included Accessories

`accessories/accessory` entries are installed when the weapon is created. They are marked included and given Cost handling from the accessory catalog.

**name** (required): accessory name or id from [**accessory**](#accessory "accessory").

**rating** (optional): integer Rating.

**mount** (optional): presence flag. When this element is omitted, the accessory is installed on `Internal` with extra mount `None`. When it is present, the installed mount is the catalog accessory's `mount` text. The text of this element is not used.

**extramount** (optional): presence flag read only when `mount` is also present. When this element is present, the extra mount is the catalog accessory's `extramount` text. When it is absent, the extra mount is `None`.

**gears** (optional): `usegear` children added to the accessory. Each `usegear` may contain `name`, `category`, `rating`, `capacity`, `source`, and `page`. Attributes on `name`: `select`, `qty` (default `1`), `createchildren`, and `addimprovements`. A `capacity` child is stored as `[value]`, with brackets added by the weapon. Gear Cost is set to `0`.

## <a id="accessory"></a>Accessory Node

Accessories live under `accessories/accessory`.

**id** (required): GUID. All ID fields are standard GUIDs, which can be generated by [external websites](https://www.guidgenerator.com) or plugins.

**name** (required): the name of the accessory.

**mount** (required for selection): comma-separated mounts this accessory can use, such as `Barrel` or `Under`. Select Weapon Accessory matches this against the weapon's slots. The value is not copied as the installed mount; the installed mount is chosen when the accessory is added.

**extramount** (optional): second mount required by the accessory, matched the same way as `mount`.

**addmount** (optional): extra mount string stored on the accessory after it is created.

**source** / **page** (required): book reference. See [books.xml](Books "books.xml").

**avail** (optional): Availability.

**cost** (optional): Cost. Supports `Variable(min-max)` and `Variable(min+)`. When omitted, Cost is `0`.

**weight** (optional): encumbrance string.

**rating** (optional): maximum Rating. The installed Rating is clamped to this maximum.

**ratinglabel** (optional): string-table key for a custom rating prompt label.

**rc** (optional): Recoil Compensation granted by the accessory.

**rcdeployable** (optional): when `True`, the recoil bonus applies only while the accessory is deployed.

**rcgroup** (optional): integer group. Accessories in the same recoil group do not stack.

**conceal** (optional): Concealability modifier.

**accuracy** (optional): Accuracy modifier. `0`, `+0`, and `-0` are stored as empty.

**reach** (optional): Reach modifier. `0`, `+0`, and `-0` are stored as empty.

**ap** (optional): Armor Penetration modifier.

**apreplace** (optional): replaces the weapon's Armor Penetration instead of modifying it.

**damage** (optional): Damage modifier.

**damagereplace** (optional): replaces the weapon's Damage.

**damagetype** (optional): Damage type override.

**dicepool** (optional): dice pool modifier.

**firemode** (optional): firing mode string stored on the accessory.

**firemodereplace** (optional): replaces the weapon's firing modes.

**addmode** (optional): mode appended to `firemode` with `/` when it is not already present. When `firemode` is empty, `addmode` becomes the fire mode.

**replacerange** (optional): replaces the weapon's range category.

**rangebonus** / **rangemodifier** (optional): range adjustments.

**modifyammocapacity** (optional): expression that changes ammunition capacity.

**ammoreplace** (optional): replaces the ammunition capacity string.

**ammobonus** (optional): extra ammunition capacity.

**ammoslots** (optional): integer number of additional clips this accessory provides. Those clips are created on the parent weapon.

**accessorycostmultiplier** (optional): integer multiplier applied to other accessories' costs.

**specialmodification** (optional): when `True`, the accessory is a special modification.

**allowgear** (optional): Gear that may be installed in the accessory. Same role as cyberware `allowgear`. See [Cyberware](Cyberware).

**gears** (optional): bundled `usegear` children, resolved from [gear.xml](Gear "gear.xml") by `name` and optional `category`.

**wirelessbonus** / **wirelessweaponbonus** (optional): bonus nodes applied when the accessory's wireless bonus is active. See [Improvement Manager](Improvement-Manager).

**extra** (optional): extra text stored on the accessory.

**notes** / **altnotes** / **notesColor** (optional): default notes text and highlight color. `altnotes` is preferred when both are present.

**hide** / **ignoresourcedisabled** (optional): sourcebook-filter visibility, same as on weapons.

## <a id="clips"></a>Clips

`Clip` is not a weapons.xml element. When a weapon is created, one clip is added for each `ammoslots` value (default 1), and one more clip is added for each accessory whose `ammoslots` provides a clip.

Weapons with `requireammo` false, and with an ammo string that is not empty or `0`, rebuild a single internal clip. The capacity is the first numeric capacity parsed from the ammo string. Strings that contain `x`, `×`, `+`, ` or `, `Special`, or `External Source` are split on ` or `. The suffix ` + energy` is removed, and ` or belt` is treated as ` or 250(belt)`. The count is the text before the first `(`.
